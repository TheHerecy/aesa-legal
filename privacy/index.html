Aesa Agent Privacy Policy

Blackbox Intelligence Group LLC · Effective 21 September 2026

Aesa Agent is a native Android client. It does not run a local model and it has no developer backend. You sign in or paste an API key, or you point the app at an OpenAI-compatible URL you control. Chat content is sent only to the endpoint you configure.

What we collect

Blackbox Intelligence Group LLC does not collect, sell, or share your chats, keys, photos, or location. There is no analytics SDK, no crash SDK that uploads chats, no ads, and no required Aesa account.

Data that stays on the device:

  • Conversation history
  • Durable notes / memory
  • Provider configuration (API keys are not stored in the chat database)
  • Phone Access grants and a local audit of recent phone-tool executions
  • Flags on assistant messages (Play AI-generated content policy)

API keys are stored in EncryptedSharedPreferences backed by Android Keystore.

Data you send to third parties

When you send a message, the app transmits conversation text (and attached photos, if you attach them) to the provider you enabled — for example OpenAI, Anthropic, xAI, DeepSeek, Moonshot/Kimi, OpenRouter, Google Gemini, or a host you type (Ollama, LM Studio, vLLM, llama.cpp).

Those providers are third parties you choose. We do not interpose a proxy.

If you enable Phone Access and confirm a tool:

  • Location, clipboard, notification text, or contact display info may be included in the next model turn, only after Confirm.
  • dial_number and compose_sms open the system dialer / SMS app. Aesa Agent does not place calls or send SMS.

LAN / cleartext

Custom endpoints on your LAN (for example http://192.168.x.x:11434/v1) may use unencrypted HTTP. That is required for typical homelab Ollama. Prefer Tailscale or HTTPS when you can.

Permissions

Used for app functionality, optional, not sold: Internet; Microphone (system speech recognizer); Camera (optional capture; Photo Picker is preferred); Location (one-shot, only when the location tool is confirmed); Notifications (Phone Access status; optional Notification Listener); Foreground service (keeps a stream / Phone Access session visible).

The Play flavor does not request SMS, call log, Accessibility, all-files, overlay intercept, or install-unknown-apps.

Security

TLS for non-LAN hosts. Certificate pinning is off in v1 so custom endpoints work. Auto Backup is disabled so keys are not included in cloud backup.

AI-generated content

Responses are generated by the AI provider you connect. You can flag any assistant message in-app.
